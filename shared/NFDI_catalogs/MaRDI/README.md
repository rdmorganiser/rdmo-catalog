Allgemeine Informationen 
============================ 

Der MaRDI-DMP-Katalog ist eine Unterstützung für Forschende beim Umgang mit Forschungsdaten entsprechend den Anforderungen der Fördergeber. 

Der Katalog wurde in Übereinstimmung mit der [Handreichung des Fachkollegiums 3.21 Mathematik der DFG](https://www.dfg.de/resource/blob/176136/handreichung-fachkollegium-mathematik-forschungsdaten.pdf) erstellt, an der MaRDI unterstützend mitgewirkt hat. 

Erstellt von: [Marco Reidelbach](https://orcid.org/0000-0002-1919-1834), [Sabine Schönau](https://orcid.org/0009-0003-7559-6320). Version 1.0, 07/2026. 

Ein Dienst von MaRDI4NFDI, entwickelt im Rahmen von [DMP4NFDI](https://dmp.services.base4nfdi.de/) unter Nachnutzung des NFDI Template Frameworks Version 2.0.0.
