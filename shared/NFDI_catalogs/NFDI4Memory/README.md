Allgemeine Informationen
============================

Der NFDI4Memory-Katalog für DFG-Förderanträge ist eine Unterstützung für Antragstellende beim Ausfüllen des Antragskapitels 2.4 „Umgang mit Forschungsdaten“ in DFG-Förderanträgen. 

Der Katalog wurde in Übereinstimmung mit den [Handreichungen des Fachkollegiums 1.12 Geschichtswissenschaft der DFG](https://www.dfg.de/resource/blob/401324/handreichung-fk-112-geschichtswissenschaften.pdf) erstellt, an denen NFDI4Memory unterstützend mitgewirkt hat.  
Erstellt von: [Constanze Buyken](https://orcid.org/0000-0001-8826-952X), [Fabian Cremer](https://orcid.org/0000-0001-8251-9727), [Sabine Schönau](https://orcid.org/0009-0003-7559-6320). Version 1.0, 08/2026. 

Ein Dienst von [NFDI4Memory](https://4memory.de/), entwickelt im Rahmen von [DMP4NFDI](https://dmp.services.base4nfdi.de/) unter Nachnutzung des [NFDI Template Frameworks Version 1.0.0](https://zenodo.org/records/16737079).
